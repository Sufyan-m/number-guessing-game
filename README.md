# 🎲 NUMBER GUESSING GAME 🐍💀
Bro thinks he can beat the system... 😭

YOOOOO! ⚡

So yeah, I made a little Python game where the computer picks a random number between 1 and 10, and you try to guess it.

Easy, right? 🤨 Let's see about that. 😂

## 🎮 How to Play?
*   🔢 Enter a number between 1 and 10.
*   🎲 The computer secretly picks a number.
*   📉 **Too low?** Bro, aim higher!
*   📈 **Too high?** Calm down, sniper!
*   🏆 **Correct guess?** YOU BEAT THE SYSTEM!

Simple game. Massive brain energy. 🧠🔥

## 🛠️ Made With
*   🐍 Python
*   🎲 `random` module
*   🤔 `if / elif / else` conditional logic
*   💻 My own keyboard and brain

## 🚀 How to Run
1.  Make sure Python is installed.
2.  Clone this repository.
3.  Open the project folder in your terminal.

Run the script:
```bash
python number_guessing_game.py
```

*Start guessing. Don't embarrass yourself.* 💀
